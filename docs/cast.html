Kairo Cast

Récepteur de recopie d'écran pour Android TV : l'écran du Mac, de l'iPhone ou du PC Windows s'affiche sur la TV, avec le son, sans limite de durée. Jusqu'à quatre écrans en mosaïque.

Kairo Cast pour la box Kairo Cast pour Windows Code source
Recopier l'écran

Mac, iPhone ou PC, en deux clics.

Mac, iPhone, iPad (AirPlay)

Centre de contrôle › Recopie de l'écran › « Kairo ». Rien à installer : la TV affiche l'écran avec le son. Même menu pour arrêter.

PC Windows 10/11

Lancez KairoCast.exe, appuyez sur Win+K : le panneau « Partager l'écran vers… » liste les box Kairo du réseau et l'état de chaque source (libre, occupée par PC-Bureau, occupée (Mac ou iPhone)). Partager, et l'écran du PC passe sur la TV, avec le son.

Dupliquer ou Étendre

La TV devient un écran de Windows pendant le partage : Win+P › Dupliquer ou Étendre, comme un écran branché. Hors partage, l'écran virtuel n'existe pas ; à l'arrêt, la disposition des écrans d'avant revient.

Pourquoi une appli Windows ?

Windows ne sait pas envoyer son écran en AirPlay, et une appli Android ne peut pas recevoir le Miracast natif. Kairo Cast pour Windows capture l'écran, l'encode par la carte graphique et l'envoie à la box sur le réseau local.

Fonctions

La TV, toujours prête à recevoir.

Jusqu'à quatre écrans

Nombre de sources de 1 à 4 : chaque source a son propre nom et s'affiche en mosaïque (Remplir l'écran ou Formats exacts). Netteté réglée automatiquement : 1800p à deux, 800p à trois ou quatre.

Le son qui suit

Le son du Mac ou du PC est joué sur la TV. À plusieurs sources, une seule est audible : par défaut celle de la tuile sélectionnée, ou une source choisie.

Netteté réglable

Standard (1200p), Haute (1600p, par défaut) ou Maximale (2160p). Sur le PC : 1080p 30 ou 60 i/s, ou 1440p 30 i/s.

Affichage

Une source seule : Étirer, Remplir ou Ajuster, à la touche OK de la télécommande. À plusieurs : flèches pour choisir une tuile, OK pour l'agrandir, Menu pour l'écouter.

Démarre avec la box

Toujours prête à recevoir, sans limite de durée ni abonnement. Option Ouvrir à l'allumage de la TV : l'accueil de Kairo Cast s'affiche dès que la TV s'allume.

Open source

Code source sur GitHub (GPL-3.0, basé sur UxPlay).

Installation

Installer Kairo Cast.

Sur la TV ou la box

Android TV 11 ou plus récent. Downloader : code 2534592, ou le lien direct kairo-cast.apk, ou depuis Kairo (assistant ou « Nos applications »). L'ouvrir une fois : elle démarre ensuite avec la box.

Sur le PC Windows

Windows 10 1903+ ou 11, 64 bits. Téléchargez KairoCast.exe et lancez-le, rien à installer. SmartScreen : « Informations complémentaires › Exécuter quand même ». Au premier partage, autorisez l'appli sur le réseau privé.

Autorisation (une fois)

Pour que la recopie s'ouvre par-dessus une autre appli : Réglages › Afficher par-dessus les autres applis, ou par ADB :

adb shell appops set com.vantaflow.kairo.cast SYSTEM_ALERT_WINDOW allow

Box introuvable sur le PC ?

Même réseau, réseau privé autorisé, Kairo Cast ouvert une fois sur la box ; sinon, dans la fenêtre de l'appli Windows, Box introuvable ? Ajouter par adresse IP (adresse affichée sur l'accueil de Kairo Cast).
