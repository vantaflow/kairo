Kairo Cast

Récepteur de recopie d'écran pour Android TV : l'écran du Mac ou du PC Windows s'affiche sur la TV, avec le son, sans limite de durée.

Kairo Cast pour la box Kairo Cast pour Windows Code source
Recopier l'écran

Mac ou PC, en deux clics.

Sur Mac (AirPlay)

Centre de contrôle › Recopie de l'écran › « Kairo ». L'écran s'affiche sur la TV.

Sur Windows 10/11

L'application Kairo Cast pour Windows › Recopier. Encodage par la carte graphique (NVIDIA, Intel, AMD), un seul fichier à lancer, rien à installer.

Fonctions

La TV, toujours prête à recevoir.

Le son aussi

Le son du Mac ou du PC est joué sur la TV.

Netteté réglable

1080p, 1440p (par défaut) ou 4K.

Affichage

Étirer (par défaut), Remplir ou Ajuster.

Démarre avec la box

La TV est toujours prête à recevoir, sans limite de durée.

Installée en un clic

Proposée dans l'assistant de premier lancement de Kairo et dans « Nos applications ».

Open source

Code source sur GitHub (GPL-3.0, basé sur UxPlay).

Installation

Installer Kairo Cast.

Sur la box

Depuis Kairo (assistant ou « Nos applications »), ou par l'APK : kairo-cast.apk.

Sur le PC Windows

Téléchargez KairoCast.exe et lancez-le, puis Recopier.

Autorisation (une fois)

Une autorisation est à donner une fois par ADB pour que l'appli s'ouvre quand le Mac se connecte :

adb shell appops set com.vantaflow.kairo.cast SYSTEM_ALERT_WINDOW allow
