Kairo Remote

Le téléphone devient la télécommande, sans rien installer : scannez le QR code affiché par la box et la page s'ouvre dans le navigateur, iPhone ou Android.

Télécharger Kairo Code source

Intégré à Kairo : Réglages › Télécommande sur téléphone

Fonctions

Tout le canapé dans la poche.

Télécommande

Flèches, OK, Retour, Accueil, lecture, volume (appui maintenu = répétition, glisser sur le pavé).

Clavier

Le texte va dans le champ ouvert sur la box, sinon il lance une recherche dans Kairo.

Applis

La liste avec icônes, un appui pour ouvrir.

Envoi de fichiers et d'APK

Un APK s'installe (confirmation sur la télé), les autres fichiers vont dans Téléchargements › Kairo.

Une vidéo ou une musique envoyée du téléphone s'ouvre directement dans Kairo Player.

Sécurité

Réseau local seulement, lien protégé par un jeton (renouvelable), désactivé par défaut.

Activer

Prêt en trois étapes.

Installer Kairo

Dans Downloader, tapez le code 5568887, ou récupérez l'APK de la dernière version.

Activer

Kairo Remote est désactivé par défaut : ouvrez Réglages › Télécommande sur téléphone.

Scanner

Scannez le QR code affiché par la box : la télécommande s'ouvre dans le navigateur du téléphone.
