Reprenez Netflix, YouTube, SmartTube, TiviMate… là où vous vous étiez arrêté, avec l'ordre que vous choisissez.

Kairo Remote

Votre téléphone devient la télécommande.

Scannez le QR code affiché par la box : la télécommande s'ouvre dans le navigateur du téléphone, sans appli à installer.

  • Flèches, OK, retour, lecture et volume
  • Clavier : tapez une recherche ou un mot de passe depuis le téléphone
  • Lancez une appli, envoyez des fichiers ou installez un APK

Performance

Optimisé image par image.

Chaque écran a été profilé avec les traces système de la box (Mecool KM7 Plus, Android 14, 2 Go, 32 bits).

Navigation dans les recommandations

Temps médian par image

Avant~95 ms
Kairo aujourd'hui34 ms

Ce qui fait la différence

  • Fonds figés dans une texture, jamais redessinés en naviguant
  • Zoom et contour au dessin : aucune recomposition au focus
  • Une affiche décodée une seule fois, en RGB 565
  • Suivi d'accessibilité Compose coupé (≈ 100 ms gagnées par seconde)
  • Build R8, profil de démarrage, compilation à l'avance
